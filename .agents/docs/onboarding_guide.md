# 🚀 Antigravity 团队极简接入指南 (保姆级 Onboarding)

这是一份专为**全员（含非技术背景成员）**设计的极限防呆、图文教程手册。
没有技术门槛。只需跟着以下 4 步无脑操作，3 分钟即可为您的个人电脑挂载一位全年无休的顶级 AI 架构师辅助你完成所有工作。

---

## 🛠️ Step 1. 系统环境准备与软件安装

Antigravity IDE （反重力环境）是一款集成了最核心 AI “大脑”的专属智能办公与编程台。

**1. 您目前的电脑系统** 
无论是哪种电脑系统，均可流畅使用：
- 🍎 **MacOS (苹果系统)**：全面原生兼容 Apple Silicon (M1/M2/M3系) 及老款 Intel 芯片。（**首选推荐环境**）
- 🪟 **Windows (微软系统)**：支持 Windows 10/11。如果在后续用到高阶的自动化测试或编译流，我们会建议你安装 WSL2。但现在，仅日常运行无需操心。

**2. 下载核心客户端** 
👉 **点击此处前往官网下载 Google Antigravity 安装包：** [https://antigravity.google.com/download](https://antigravity.google.com/download)


下载后：
- Mac 用户：双击 `dmg` 安装包，将图标拖拽进 `Applications (应用程序)` 文件夹即可。
- Windows 用户：双击 `exe` 文件，狂点“下一步”进行安装。

---

## ⚙️ Step 2. 软体启动与初始秘钥配置

首次双击打开这套 IDE 软件时，由于它的核心是一具空壳，我们需要赋予它“思考”与“连接团队”的特权。

1. 在软件界面的最右下角，或是顶部菜单栏找到 **Settings/Preferences (偏好设置)** -> **Model Config (模型配置)**（根据你的软件版本可能叫 `API Key` 配置项）。
2. 在弹出的密钥框内，**粘贴填入团队为你单发的专属 AI 秘钥锁**（如 Gemini / Claude 的 API 密语）。

![图示1：在此处唤出设置并填入团队大底座 API Key 的区域](/Users/yongqian/Desktop/Antigravityknowhow/assets/tutorial_setup_api_key.png)
> *(💡 注意：本截图为占位示意图，如需具体图解请参考内网论坛；如果你手上还没有这段秘钥字符串，请先停在此步，向团队管理员索要)*

3. 确认保存后，等待右侧对话提示窗或状态栏呈现 **绿灯连通标志 🟢**，说明大脑已被激活。

---

## 📂 Step 3. 创建阵地并拉取主线结构

AI 就像个搬砖工，他需要有一块“砖厂”才能为你工作。接下来我们要把团队的核心目录盘拉到你的电脑桌面上。

1. 回到你的电脑主桌面（Desktop）上。
2. 唤醒系统**终端命令行**工具：
   - 🍎 Mac 用户：按 `Command + 空格`，搜字母 `Terminal`，点击深色图标打开。
   - 🪟 Windows 用户：按 `Win 键`，搜字母 `cmd` 或者是 `PowerShell`，回车打开。
3. 复制下方灰色框里的这两行带有英文的魔法字符。然后在打开的深黑框界面中用鼠标右键粘贴（或者系统快捷键粘贴），最后必须**重重敲击一下 `回车键 (Enter)`**：

```shell
cd ~/Desktop
git clone https://github.com/Albertsun6/AntigravityOnboard.git
```
*(这串命令的含义是：喂，跑到我的桌面上，帮我把远端的名为 AntigravityOnboard 的基建全息工程下载到桌面上！)*

4. **进厂就绪**：再次点开刚刚装好的 Antigravity IDE 软件，在欢迎页正中央点击庞大的 `Open Folder (打开文件夹)` 按钮。在弹出的系统对话框里，点击桌面（Desktop），选中那个刚刚因为命令而凭空出现的 `AntigravityOnboard` 文件夹包，点击确认打开。

---

## ⚡ Step 4. 收割一键自动组装 (输入 Onboard 口令)

这是见证智能体体系运转魔法的一刻，你只需要打一句话就大功告成。由于上一步目录已灌入，IDE 的大门已经打开，目光去向右侧的输入框。

**现在，不需要任何寒暄、不需任何多余的客套字符。原封不动地将这串大写加小写的团队口令复制进去，按回车发出：**

```text
请帮我执行团队的 /onboard 流程
```

![图示2：在右侧对话输入框精准向模型抛出这句唯一的启动执行口诀](/Users/yongqian/Desktop/Antigravityknowhow/assets/tutorial_onboard_prompt.png)

指令触发后，你的鼠标和键盘可以去休息了。系统收到口令后的半分钟时间里，它会在你的眼皮底下完全接管电脑阵地，并伴随着终端指令的飞快闪动：
- 🟢 自动为你拷贝团队顶级架构师性格的全局指令 (`GEMINI.md`)。
- 🟢 自动挖掘出规避系统拦截的防误删安全隔离区。
- 🟢 自动拉起 13 个深潜高纬度的功能辅助引擎链 (Skills)。
- 🟢 自动挂载公司领域所有的排雷经验图谱库 (Knowledge)。

直至最后，当 AI 停止输出，并甩给了你一份 **“✅ 满分全绿” 的环境 Onboarding 验证合格检验单** 时！
**恭喜，您已正式化身为被底层大架构全面加持装甲的主脑操作员，可以开始接受更纯粹的开发指令了。**

## ⚔️ 关门绝学：请把它当机器，不要全用人情世故
因为 AI 运转依赖非常昂贵的 Token 计算费用，请牢记团队为你精炼的最常用的“命令式符码”，**不要随意聊天，要直击要害**！

| 如果你想... | 请在要求后面附带加上这个词 | 它底层的原理是 |
|---|---|---|
| **“废话别多直接操作”** | 加上：`直接做` | 系统将强行无视冗长的防呆架构计划单审批过程（规划模式），跳过废话，当场帮你篡改落地生成所需的文件或代码。 |
| **“干完活儿兜底检查”** | 加上：`验收` | 你刚搞了一顿操作怕拉胯时使用，它会拉出无死角的“产品功能、界面畸变、深度死角”多维度门禁扫描系统充当老手帮你过审排沙。 |
| **“这好主意必须沉淀”** | 抛出：`记住 <你想留存的原因>` | 直接帮你把刚才这套逆天的骚操作抽成精髓结晶注入持久化的 Knowledge 经验库里，就算是明天断电系统也绝不丢失该记忆。 |
| **“聊太累了重启话题”** | 抛出：`开新局` | 对话轮次太多 AI 必瞎必失忆。它会主动总结这一局的所有干货切片甩给你，你只要复制带着这段小票凭据开启全新的清爽聊天会话，战备重燃无缝对接。 |

欢迎登舰，航行顺利。
