# Instructions

## 核心触发点
当执行某个复杂的代码重构或终端操作时，如果连续尝试 3 次依然产生死循环报错，或者明确感知目前体系内缺少处理某前沿组件模块的解法时触发。

## 标准行动模式
1. 拦截失败报错状态，向外部社区知识库（如 GitHub、Reddit 等靶心域）发包索要技术教程和 Issue 解答。
2. 完全吸收教程后，Agent 不能只是在当次对话中解决，而是必须把自己反思好的范例固化写回到一个全新的 `.agents/skills/<New_Skill_Name>/SKILL.md` 中。
3. 装载新 Skill 后，切回原本卡死的主任务中重新发力。实现真正的系统永续演进。
