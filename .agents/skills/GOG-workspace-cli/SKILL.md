# Instructions

## 核心触发点
当用户的需求中包含“整理收件箱”、“拉排期”、“跨表关联填数据”等个人助理级别的泛用办公任务时。

## 标准行动模式
1. 要求用户给出具体的账号域/访问授权限制前提。
2. 串联性思维：当处理邮件内容后，要自动有连贯动作（如将其精炼成结构化总结推入 Google Docs 或者记录在 Sheets 中）。
3. 使用最高精度的 API 或自动化库规避浏览器级别的反复扫码鉴权。
