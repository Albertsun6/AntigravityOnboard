# Instructions

## 核心触发点
当用户下达关于 Odoo、复杂业务后台或是具有防爬限制的前端页面的自动化交互测试/数据提取要求时。

## 标准行动模式
1. 绝不盲目依赖脆弱的 DOM `X/Y` 坐标。强制执行 Snapshot-First（先截图后定位）策略。
2. 对于页面遮挡物（如 Chrome 密码保存警告弹窗、Odoo 欢迎导览页），必须先执行独立的除障点击。
3. 确保模拟真实的输入律动和鼠标轨迹，最大化提高自动化 E2E 的穿透能力。
