# Instructions

## Phase 1: 侦察与情报收集 (Scouting)
1. 使用 `search_web` 工具执行无边际搜索。**不限制任何技术领域或作用范围**（涵盖前端界面探索、DevOps、数据库探针、个人自动化办公流、底层驱动扩展乃至多媒体全模型处理等任何可能方向）。
2. **核心筛选逻辑：唯热度论**。优先从 clawhub 等代理能力中心以及 GitHub (如各类高赞 `awesome-*` 聚合库) 进行探测，必须以社区 Stars 数、下载量或现象级讨论热度作为最主要且唯一的入选基准。只带回最能引发共鸣的顶级工具。
3. 价值信息提炼：提取这些顶流装备的【名称】、【核心震撼功能】、【社区高热度数据证明】、【跨界应用场景】和【来源 URL】。

## Phase 2: 持久化生成报告 (Reporting)
1. 将侦察带回的高热度数据进行结构化包装。
2. **强制持久化保存：** 将汇总后的火力报告直接写入本地持久化目录（推荐使用系统内置的 Artifacts 工具或存为 `.agents/docs/skills_report.md`）。
3. 同样严禁直接自动建库！必须在报告中对每一个高热度 Skill 加上一目了然的数字序号 `[1]`, `[2]` ... 和星星等视觉强调，供挑选。

## Phase 3: 暂停与确认转化 (Yield & Convert)
1. **向用户汇报：** 发送刚打好的超链接，给出一句话极致精要的核心汇报。
2. 暂停执行（Yield Control），弹出询问：“全网不限领域的顶流 Skills 报告已持久化。你要把哪几个热门神器收编为我们的原生指令操作？（输入对应序号即可）”
3. 等待具体的明确指令输入后，再启动代码构建动作，落盘写入具体的 `.agents/skills/<name>/SKILL.md`。
